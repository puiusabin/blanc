### 📖 About this Repository
This repository contains the original implementation of **Blanc**, a Web3-native mail application. It remains public for historical reference and to preserve the early development history of the project.

#### Original Feature Set
- **Web3 Identity**: Wallet-based authentication using `wagmi` and `viem`.
- **SMTP Bridge**: Custom Haraka-based mail server integration.
- **Modern Stack**: Next.js App Router, Tailwind CSS, and Prisma ORM.
- **Edge Deployment**: Optimized for Cloudflare Workers.
